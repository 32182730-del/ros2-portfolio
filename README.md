# ROS 2 & Physical AI Learning Portfolio

## 🎯 Objective
This repository documents my 5-month journey from a Linux beginner to a ROS 2 Developer, with a final goal of building a simulated Mobile Manipulator (Physical AI) for graduate school applications. 

## 🛠️ Tech Stack
- **OS:** Ubuntu 26.04 LTS
- **ROS 2 Distro:** Lyrical Luth
- **Languages:** Python, C++
- **Simulation:** Gazebo
- **Tools:** Git, VS Code, DeepSeek (Architecture), Gemini (Debugging)

## 📂 Repository Structure
- [`/notes`](./notes): Theoretical concepts, Linux commands, and ROS 2 architecture.
- [`/ros2_ws`](./ros2_ws): ROS 2 workspace containing custom packages and nodes.
- [`/projects`](./projects): Mini-projects and capstones.
